# WPFGeometriePfad

Ein Visual-Studio-Projekt zur Einführung in die Erstellung und Darstellung geometrischer Pfade innerhalb einer WPF-Anwendung.

## Beschreibung

Das Projekt **WPFGeometriePfad** beschäftigt sich mit den Grundlagen der geometrischen Darstellung in Windows Presentation Foundation (WPF). Im Mittelpunkt stehen die Verwendung von Pfadgeometrien, die Erstellung geometrischer Formen und die grafische Darstellung von Linien und Kurven innerhalb einer Benutzeroberfläche.

## Funktionen

- Darstellung geometrischer Formen und Pfade
- Verwendung des Path-Steuerelements
- Erstellung von Linien und Kurven
- Gestaltung komplexerer geometrischer Figuren
- Grundlagen der Vektorgrafik mit WPF und XAML

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Presentation Foundation (WPF)
- XAML

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WPFGeometriePfad.git
   ```

2. Die Datei `WPFGeometriePfad.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
